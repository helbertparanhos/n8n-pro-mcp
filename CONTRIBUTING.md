# Contributing

Contributions are welcome!

1. **Fork** this repository
2. Create a branch: `git checkout -b feature/my-feature`
3. Commit using [Conventional Commits](https://www.conventionalcommits.org/): `git commit -m 'feat: add my feature'`
4. Push: `git push origin feature/my-feature`
5. Open a **Pull Request**

## Development

```bash
npm install
npm test            # build + unit tests (node:test)
npm run inspector   # interactive testing with @modelcontextprotocol/inspector
```

## Reporting bugs / suggesting features

Use the [issue templates](.github/ISSUE_TEMPLATE/) — include reproduction steps, environment (Node version, n8n version, queue mode or not) and relevant logs (never paste API keys).
